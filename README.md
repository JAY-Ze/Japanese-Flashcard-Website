🇯🇵 Japanese Kana Flashcards

A minimalist, modern flashcard web app for learning Hiragana & Katakana

📌 Overview

This project is a responsive flashcard web application designed to help learners master Japanese Hiragana and Katakana through active recall.

Instead of multiple-choice guessing, users type the Romaji translation for each character, receive instant feedback, and see real Japanese words that use the character — improving both recognition and context.

Built with HTML, Tailwind CSS, and Vanilla JavaScript, the app is lightweight, fast, and beginner-friendly.


✨ Features
✅ Full Hiragana & Katakana (Gojuon) coverage
⌨️ Type-based answer input (active recall)
⚡ Instant correct / wrong feedback
📚 Common Japanese words for context
🔁 Randomized flashcards
🎛 Toggle between Hiragana & Katakana
📱 Fully responsive & mobile-friendly
🎨 Minimalist, modern UI


🛠 Tech Stack
HTML5 – structure
Tailwind CSS (CDN) – layout & responsiveness
Custom CSS – premium UI polish
Vanilla JavaScript – logic & flashcard system
No frameworks. No build tools. No dependencies.

🧠 How It Works
A random Hiragana or Katakana character is displayed
You type the Romaji equivalent
The app checks your answer:
✅ Correct → positive feedback
❌ Wrong → shows correct Romaji
Common Japanese words using that character are displayed
Move to the next character

🎯 Learning Philosophy
This app is based on:
Active recall (typing, not guessing)
Immediate feedback
Contextual learning via real words
Minimal UI to reduce cognitive load
The goal is fast kana mastery, not gamification clutter.
